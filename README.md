# 📌 Overview

**StegSecure** is a GUI-based steganography tool developed for securely hiding and extracting confidential information inside image and audio files.

The project focuses on cybersecurity and information hiding techniques using steganography concepts. It allows users to embed secret text messages inside multimedia files without visibly changing the original file appearance.

This tool is useful for:
- Secure communication
- Digital watermarking
- Cybersecurity research
- Data hiding applications
- Digital forensics

# 🧠 Working Principle

The project uses **Least Significant Bit (LSB)** steganography technique to hide secret information inside media files.

### Steps:
1. Select Image/Audio File
2. Enter Secret Message
3. Encrypt & Encode Message
4. Save Encoded File
5. Extract Message Using Tool
